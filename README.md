# Momently MVP

Working brand: MOMENTLY — Make the moment happen.

Edmonton-focused celebration marketplace MVP.

## Run
npm install
npm run dev

## Deploy
Push to GitHub, then import the repository into Vercel. Vercel supports automatic Next.js detection and Git-based deployments.

Sample listings are placeholders, not partner businesses. Booking, authentication, payments, provider onboarding, live availability, reviews and database functionality come next.
